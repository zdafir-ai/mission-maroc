# Mission Maroc (test Android)

Application de test pour enfants de 5-7 ans. Elle fonctionne sans internet.

## Obtenir l'APK

1. Dépose tout le contenu de ce dossier dans un dépôt GitHub privé, y compris le dossier `.github`.
2. Ouvre l'onglet **Actions** du dépôt et attends la coche verte.
3. Clique sur la compilation, puis télécharge **Mission-Maroc-APK** en bas de la page.
4. Décompresse le fichier téléchargé : il contient `app-debug.apk`.

## Installer sur le téléphone

Envoie `app-debug.apk` sur le téléphone, ouvre-le et autorise l'installation depuis cette source.

Cet APK sert uniquement aux tests. Il n'est pas destiné à Google Play.
